# Subway Simulator Prague Metro – V2.0

Moderní pokračování / obnovení projektu Subway Simulator Prague Metro.

## Stav projektu

Počáteční vývoj / prototyp

## Plánované technologie

- Unity
- C#
- Blender

## Cílové platformy

- Android
- iOS – bude zváženo podle zájmu
- PC – případná budoucí platforma

## Plánované funkce

- Realistické 3D prostředí metra
- 3D trať založená na spline křivce
- Více typů souprav
- Realistické ovládání a fyzika vlaku
- Stanice a tunely
- Modulární a rozšiřitelná architektura
- Možnost pozdějšího přidání dalších tratí a měst

## Projekt

Projekt je v současné době v rané fázi vývoje a prototypování.
Konečný rozsah projektu, technická architektura a způsob společného vývoje
budou ještě upřesněny.
